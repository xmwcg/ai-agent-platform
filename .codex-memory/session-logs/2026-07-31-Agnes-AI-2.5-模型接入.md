# 2026-07-31 会话记录：Agnes AI 2.5 模型接入

## 项目

NexMind Platform / AIbak（`ai-agent-platform`）

## 任务

为所有 AI 对话、智能客服、AI 对话体验、智能工具箱及其他模型调用入口增加 Agnes AI 2.5 的 OpenAI 兼容接入：

- 凭据：仅通过运行时环境变量注入，未写入源码、Git 或知识库

## 实施摘要

1. 新增独立 `agnes25` provider，读取 `AGNES25_API_KEY`（兼容 `AGNES_25_API_KEY`）与 `AGNES25_BASE_URL`，默认地址为用户提供的 Agnes API 地址。
2. 保留原有 `agnes` provider、旧 `AGNES_BASE_URL`、`agnes-2.0-flash`、图片模型和视频模型，没有删除、替换或覆盖旧配置。
3. 统一 AI Gateway、AIModelManager、免费用户路由、代码解释工具接入新模型。
4. 模型配置中心新增 Agnes AI 2.5 Provider Catalog / 前端预设；AI 对话页、首页体验、客服模型选择、知识库 AI 解读、短视频工作流均可选择或使用新模型。
5. Agnes 媒体 Provider 改为只选择包含 image/video 模型的配置，避免文本专用 Agnes 2.5 配置抢占文生图/视频通道。
6. `.env` 模板、生产模板、K8s ConfigMap/Secret 模板新增配置字段；真实 Key 需在部署平台的运行时密钥中设置：

```env
AGNES25_API_KEY=<运行时注入真实 Key>
AGNES25_BASE_URL=https://api.agnes-ai.cn/v1
```
