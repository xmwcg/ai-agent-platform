# 工业制造 · 大模型自动应答知识库

## 常见问答（示例）
1. **Q：设备报错了怎么办？**
   A：提供错误码可在「知识库-故障码」查处理步骤；无法自排请联系运维。

2. **Q：怎么预约保养/维保？**
   A：在「设备管理-维保」提交申请，系统派单。

3. **Q：备件怎么订购？**
   A：「备件商城」按型号下单；交期以页面为准。

4. **Q：工艺参数怎么查？**
   A：RAG 接工艺手册/SOP，输入产品/工序获取参数建议。

5. **Q：产线数据怎么看？**
   A：「数字孪生/看板」实时查看 OEE、良率；异常自动告警。

6. **Q：如何接入 MES/SCADA？**
   A：通过开放 API / OPC-UA / MCP 网关对接，见集成文档。

7. **Q：安全规范有哪些？**
   A：知识库收录安全操作规程（公开版），上岗须培训考核。

8. **Q：怎么提改进建议？**
   A：「持续改善」通道提交，纳入评审。

## 部署要点
- 故障码/工艺手册 RAG；敏感操作接工单系统。
- 推荐模型：`qwen-plus` / `glm-4-plus`；长手册用 `gemini`。
