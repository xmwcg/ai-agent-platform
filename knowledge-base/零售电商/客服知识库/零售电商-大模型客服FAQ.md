# 零售/电商 · 大模型自动应答客服知识库

> 用法：将下列 Q&A 作为 RAG 条目，配合「智能客服」构建售前/售后自动应答。订单/支付等敏感操作接 MCP 工具实时查询。

## 常见问答（示例）
1. **Q：怎么查物流/快递？**
   A：在「我的订单-物流跟踪」查看实时轨迹；也可凭运单号到对应快递官网查询。

2. **Q：支持哪些支付方式？**
   A：微信支付、支付宝、银行卡等；具体以结算页为准。

3. **Q：如何申请退款/退货？**
   A：「订单详情-申请售后」选择退货退款，按提示寄回；审核通过后原路退回。

4. **Q：多久发货？**
   A：现货一般 48 小时内发货；预售以商品页标注为准。

5. **Q：优惠券怎么用？**
   A：结算时勾选可用优惠券；注意门槛与有效期。

6. **Q：商品缺货/发错货怎么办？**
   A：联系客服补发或退款；发错货可申请上门取件。

7. **Q：会员权益有哪些？**
   A：积分、专属价、包邮等，详见「会员中心」。

8. **Q：发票怎么开？**
   A：「订单-申请发票」填写抬头，电子发票发送至邮箱。

## 部署要点
- 高频售前/售后用 RAG + 工具调用（查订单/物流）实现「答得准」。
- 推荐模型：`deepseek-chat`（低成本高并发）、`doubao`（营销文案）、`qwen-plus`（中文）。
