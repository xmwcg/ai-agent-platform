# 医疗健康 · 大模型应用指引

## 1. 典型场景
- 健康科普问答、就医指引（见 客服知识库）
- 报告单/影像报告结构化解读（辅助）
- 病历摘要、随访提醒
- 医学文献检索与综述
- 分诊导诊（症状→科室推荐）

## 2. 模型选型
| 任务 | 推荐模型 | 理由 |
|------|------|------|
| 中文健康科普 | qwen-plus / glm-4-plus | 中文强 |
| 长病历/文献 | gemini（1M 上下文） | 超长 |
| 私有化（HIS 数据） | 开源权重 + vLLM | 数据不出院 |

## 3. 架构建议
- RAG：权威指南（卫健委/指南共识公开版）、药品说明书入库。
- 护栏：强制免责声明 + 紧急就医提示 + 敏感词拦截 + 转人工。

## 4. 合规
- 仅用公开/授权数据；PII 脱敏；不提供诊断结论。
- 符合医疗广告与数据安全法规，建议私有化部署处理院内数据。
