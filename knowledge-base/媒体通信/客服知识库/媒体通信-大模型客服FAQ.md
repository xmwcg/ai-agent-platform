# 媒体/通信 · 大模型自动应答知识库

## 常见问答（示例）
1. **Q：套餐/流量怎么查？**
   A：在「我的-套餐」查看余量与有效期；可接 MCP 实时查询账户。

2. **Q：怎么办理变更/携号转网？**
   A：线上「业务办理」按指引；携号转网需先短信申请授权码。

3. **Q：信号/故障怎么办？**
   A：自助排障指引；仍异常派单运维，详见「报障」。

4. **Q：国际漫游怎么开？**
   A：「漫游」开通并选包；资费以页面为准。

5. **Q：内容投稿/合作？**
   A：「创作者中心」提交；商务合作联系对应邮箱。

6. **Q：版权/侵权投诉？**
   A：「侵权投诉」通道提交材料，按流程处理。

7. **Q：会员/订阅怎么退？**
   A：在「订阅管理」取消自动续费；已扣费按规则。

8. **Q：广告投放怎么开户？**
   A：「广告平台」注册开户，充值后创建计划。

## 部署要点
- 账户类接 MCP 实时；内容类 RAG 接帮助中心。
- 推荐模型：`deepseek-chat`（高并发）、`doubao`（内容生成）。
