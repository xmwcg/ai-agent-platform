# 金融行业 · 大模型应用指引

## 1. 典型场景
- 智能客服 / 7×24 应答（见 客服知识库）
- 研报/公告摘要与舆情监控
- 合规审查（合同条款、适当性、反洗钱）
- 智能投顾话术与投教
- 反欺诈：异常交易识别、可疑尽调
- 文档抽取：财报/票据/合同结构化

## 2. 模型选型建议
| 任务 | 推荐模型 | 理由 |
|------|------|------|
| 中文合规对话 | glm-4-plus / qwen-plus | 中文强、成本低、可私有 |
| 研报长文摘要 | claude / gemini（长上下文） | 超长上下文 |
| 推理/风控规则 | deepseek-reasoner / glm-z1 | 推理增强 |
| 私有化敏感数据 | 智谱/千问开源权重 + vLLM | 数据不出域 |

## 3. 架构建议
- RAG：把产品说明书、监管文件、话术库做向量化（见 客服知识库）。
- 工具调用（MCP）：接 CRM、风控系统、交易网关，实现「查余额/下单/转人工」。
- 合规护栏：输出前加敏感词过滤 + 免责声明 + 人工复核通道。

## 4. 风险与合规
- 金融答复须可审计、留痕；禁止模型直接给出确定性投资建议。
- 数据脱敏、最小授权；优先私有化部署处理 PII。
