# 专业服务（法律/财税/咨询）· 大模型应用指引

## 1. 典型场景
- 合同/条款风险标注（见 客服知识库）
- 法规/判例检索摘要
- 财税问答与报表解读
- 咨询报告草稿生成
- 文档审阅（长篇）

## 2. 模型选型
| 任务 | 推荐模型 | 理由 |
|------|------|------|
| 中文专业 | glm-4-plus / qwen-plus | 中文强 |
| 长文档审阅 | gemini / claude | 长上下文 |
| 敏感数据 | 开源权重 + vLLM | 私有化 |

## 3. 架构建议
- RAG：法规库、模板库（脱敏）。
- 护栏：强制免责 + 转执业人士。
