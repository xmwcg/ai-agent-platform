# 专业服务（法律/财税/咨询）· 大模型自动应答知识库

> 强制免责：提供科普与流程指引，**不构成法律/税务意见**，重大事项请委托执业人士。

## 常见问答（示例）
1. **Q：这个合同有没有风险？**
   A：可标注常见风险点（公开条款级），但正式审校需执业律师。

2. **Q：注册公司需要什么？**
   A：核定名称、经营范围、注册资本、住所；流程以市场监管局为准。

3. **Q：税务怎么申报？**
   A：科普申报期限与税种；具体操作以税务机关/会计师意见为准。

4. **Q：咨询怎么收费/预约？**
   A：见「服务-报价」；预约填需求由顾问回拨。

5. **Q：材料清单？**
   A：按服务类型给清单模板，可下载。

6. **Q：保密怎么保证？**
   A：签署保密条款；数据最小化授权，敏感数据私有化。

7. **Q：进度怎么查？**
   A：「我的项目」查看阶段；可接 MCP 实时状态。

8. **Q：发票/合同？**
   A：后台申请；企业合同联系商务。

- 知识库接法规/案例公开摘要；执业结论转人工。
