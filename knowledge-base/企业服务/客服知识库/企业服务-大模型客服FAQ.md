# 企业服务（SaaS）· 大模型自动应答客服知识库

## 常见问答（示例）
1. **Q：如何创建团队/邀请成员？**
   A：管理员在「团队-成员」发邀请链接或邮箱，成员接受后按角色授权。

2. **Q：支持什么套餐/计费？**
   A：见「定价」页，含免费版/专业版/旗舰版/团队版；按席位或用量计费。

3. **Q：数据安全和权限？**
   A：支持角色权限、数据隔离、操作审计；企业可签 DPA。

4. **Q：怎么提工单/报障？**
   A：「帮助-提交工单」描述问题并附截图；SLA 按套餐分级。

5. **Q：能不能对接我们内部系统？**
   A：提供开放 API / Webhook / MCP，详见开发者文档。

6. **Q：发票与合同？**
   A：后台「账单」申请发票；企业合同联系商务。

7. **Q：如何迁移/导出数据？**
   A：支持批量导出（CSV/API）；迁移见导入向导。

8. **Q：免费额度用完了？**
   A：提示升级会员或购买用量包，见「会员升级」。

## 部署要点
- 工单/账户类接 MCP 实时查询；知识库接产品文档/帮助中心。
- 推荐模型：`deepseek-chat`（成本）、`qwen-plus`（中文）。
