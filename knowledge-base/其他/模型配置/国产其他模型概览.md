# 国产其他主流模型概览

> 对前面 12 家厂商之外的国产生态补充，便于平台「模型配置」按需接入。

## 1. 百川智能 Baichuan
- 平台：https://www.baichuan-ai.com ；文档：https://docs.baichuan-ai.com
- BaseURL：`https://api.baichuan-ai.com/v1`（OpenAI 兼容）
- 代表模型：`baichuan4`、`baichuan3-turbo`、`baichuan2-53b`
- 适用：中文通用、金融、医疗。

## 2. 零一万物 Yi（01.AI）
- 平台：https://platform.lingyiwanwu.com ；文档：https://docs.lingyiwanwu.com
- BaseURL：`https://api.lingyiwanwu.com/v1`（OpenAI 兼容）
- 代表模型：`yi-large`、`yi-medium`、`yi-vision`
- 适用：通用、多模态、开源权重可私有化。

## 3. MiniMax
- 平台：https://www.minimax.io ；文档：https://www.minimax.io/document
- BaseURL：`https://api.minimax.chat/v1`（OpenAI 兼容网关）
- 代表模型：`abab6.5`、`MiniMax-Text-01`；语音/音乐模型突出。
- 适用：语音合成、角色对话、出海。

## 4. 智谱开源 / GLM 系列开源权重
- GLM-4.5 / GLM-4-9B 等开源权重可在 HuggingFace / ModelScope 拉取，私有化部署。
- 私有化后用 vLLM / Ollama 暴露 OpenAI 兼容接口，baseURL 指向本地。

## 5. 通用接入范式
所有上述均 OpenAI 兼容：`baseURL + apiKey + model`，平台 `provider-catalog.ts` 统一接入。
申请方式均为「官网注册 → API Keys → 国内支付」。
