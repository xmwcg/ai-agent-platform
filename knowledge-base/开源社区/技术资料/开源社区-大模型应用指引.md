# 开源社区 · 大模型应用指引

## 1. 典型场景
- 私有化部署（数据不出域）
- 微调/领域适配
- RAG 知识库（向量检索）
- Agent/工具编排（MCP）
- 边缘/端侧推理

## 2. 推荐开源栈
| 环节 | 项目 |
|------|------|
| 推理 | vLLM、Ollama、llama.cpp、SGLang |
| 微调 | LLaMA-Factory、MS-Swift、Unsloth |
| 向量库 | Milvus、Qdrant、PGVector、Chroma |
| 编排 | LangChain、AutoGen、CrewAI |
| 模型 | Qwen、GLM-4、Yi、DeepSeek、Llama、Mistral |

## 3. 架构建议
- 本地暴露 OpenAI 兼容接口，平台 `provider-catalog` 直连。
- RAG：文档切块→嵌入→向量检索→拼上下文。
- 合规：核对 LICENSE 商用条款。
