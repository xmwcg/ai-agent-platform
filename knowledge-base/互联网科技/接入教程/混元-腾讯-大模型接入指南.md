# 混元（腾讯 Hunyuan）大模型接入指南

## 1. 官方资源
- 腾讯云混元：https://cloud.tencent.com/product/hunyuan
- API 文档：https://cloud.tencent.com/document/product/1729
- 控制台：https://console.cloud.tencent.com/hunyuan

## 2. 接入地址
- BaseURL：`https://api.hunyuan.cloud.tencent.com/v1`（OpenAI 兼容）
- 也提供原生 `hunyuan.tencentcloudapi.com` 签名接口。

## 3. 主要模型（参考，以官方为准）

| 模型 ID | 特点 |
|------|------|
| hunyuan-turbo / hunyuan-turbos | 高性价比主力 |
| hunyuan-pro | 旗舰 |
| hunyuan-standard | 标准 |
| hunyuan-vision | 多模态 |
| hunyuan-t1 | 推理增强 |

> 价格以腾讯云计费页为准；腾讯云账号可走企业结算。

## 4. API Key 申请
1. 开通腾讯云混元；
2. 访问管理 → 密钥管理 → 创建 SecretId/SecretKey；
3. 国内支付/企业结算。

## 5. 平台配置
```
HUNYUAN_API_KEY=...
HUNYUAN_BASE_URL=https://api.hunyuan.cloud.tencent.com/v1
```

## 6. 调用示例
```js
import OpenAI from 'openai';
const c = new OpenAI({ apiKey: process.env.HUNYUAN_API_KEY, baseURL: 'https://api.hunyuan.cloud.tencent.com/v1' });
const r = await c.chat.completions.create({ model: 'hunyuan-turbo', messages: [{ role: 'user', content: '你好' }] });
```

## 7. 适用场景
中文对话、微信生态/企业微信集成、内容生成、客服、Agent。
