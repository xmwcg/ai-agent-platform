# 通义千问 Qwen 大模型接入指南

## 1. 官方资源
- 阿里云百炼（Model Studio）：https://help.aliyun.com/zh/model-studio/
- 控制台：https://bailian.console.aliyun.com
- 模型列表：https://help.aliyun.com/zh/model-studio/models

## 2. 接入地址
- BaseURL：`https://dashscope.aliyuncs.com/compatible-mode/v1`（OpenAI 兼容）
- 也支持原生网关 `https://dashscope.aliyuncs.com/api/v1/services/aigc/text-generation/generation`。

## 3. 主要模型（参考，以官方为准）

| 模型 ID | 特点 | 备注 |
|------|------|------|
| qwen-max / qwen3-max | 旗舰，最强推理 | 适合复杂任务 |
| qwen-plus | 均衡性价比 | 主力推荐 |
| qwen-turbo | 极速低成本 | 高并发 |
| qwen-long | 超长上下文 | 文档 |
| qwen-vl-max / vl-plus | 多模态视觉 | 图文理解 |
| 开源 Qwen2.5 / Qwen3 系列 | 可私有部署 | 社区活跃 |

> 价格以阿里云百炼计费页为准；新用户有免费额度。

## 4. API Key 申请
1. 开通阿里云百炼；
2. 控制台 → API Key 管理 → 创建；
3. 国内支付，企业可开票。

## 5. 平台配置
```
QWEN_API_KEY=sk-...
QWEN_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
```

## 6. 调用示例
```js
import OpenAI from 'openai';
const c = new OpenAI({ apiKey: process.env.QWEN_API_KEY, baseURL: 'https://dashscope.aliyuncs.com/compatible-mode/v1' });
const r = await c.chat.completions.create({ model: 'qwen-plus', messages: [{ role: 'user', content: '你好' }] });
```

## 7. 适用场景
全模态、企业级部署、私有化（开源权重）、中文场景、Agent。
