# 豆包（火山方舟 Volcengine Ark）大模型接入指南

## 1. 官方资源
- 火山方舟：https://www.volcengine.com/product/ark
- 豆包大模型：https://www.volcengine.com/product/doubao-dy
- 文档：https://www.volcengine.com/docs/82379/

## 2. 接入地址
- BaseURL：`https://ark.cn-beijing.volces.com/api/v3`（OpenAI 兼容）
- 注意：豆包需在火山方舟创建「推理接入点（Endpoint）」，调用用 Endpoint ID 作为 model。

## 3. 主要模型（参考，以官方为准）

| 模型 ID（接入点） | 特点 |
|------|------|
| doubao-pro / Doubao-1.5-pro | 旗舰，强推理多模态 |
| doubao-lite | 轻量低成本 |
| doubao-vision | 视觉多模态 |

> 价格以火山引擎计费页为准；企业可申请商务折扣。

## 4. API Key 申请
1. 注册火山引擎并实名；
2. 控制台 → 访问控制 → 创建 API Key；
3. 方舟控制台创建推理接入点，复制 Endpoint ID；
4. 国内支付/企业对公。

## 5. 平台配置
```
DOUBAO_API_KEY=...
DOUBAO_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
DOUBAO_MODEL=<Endpoint-ID>
```

## 6. 调用示例
```js
import OpenAI from 'openai';
const c = new OpenAI({ apiKey: process.env.DOUBAO_API_KEY, baseURL: 'https://ark.cn-beijing.volces.com/api/v3' });
const r = await c.chat.completions.create({ model: process.env.DOUBAO_MODEL, messages: [{ role: 'user', content: '你好' }] });
```

## 7. 适用场景
高并发、企业级、多模态、内容生成、客服、营销文案。
