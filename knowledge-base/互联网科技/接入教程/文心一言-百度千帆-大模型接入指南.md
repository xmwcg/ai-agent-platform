# 文心一言（百度千帆 ERNIE）大模型接入指南

## 1. 官方资源
- 千帆平台：https://qianfan.cloud.baidu.com
- 文档：https://cloud.baidu.com/doc/WENXINWORKSHOP
- 模型广场：https://cloud.baidu.com/doc/WENXINWORKSHOP/s/Qf7x3gjeh

## 2. 接入地址
- BaseURL：`https://qianfan.baidubce.com/v2`（OpenAI 兼容 `/v2/chat/completions`）
- 也支持原生 `https://aip.baidubce.com/rpc/2.0/ai_custom/v1/wenxinworkshop/chat/...` 旧接口。

## 3. 主要模型（参考，以官方为准）

| 模型 ID | 特点 |
|------|------|
| ernie-4.5 / ernie-4.0-8k | 旗舰 |
| ernie-3.5-8k | 通用均衡 |
| ernie-speed / lite | 极速低成本 |
| ernie-vilg / 多模态 | 图像/视觉 |

> 价格以千帆计费页为准；新用户赠送资源包。

## 4. API Key 申请
1. 注册百度智能云并实名；
2. 千帆 → 应用接入 → 创建应用，获取 API Key / Secret Key；
3. 用 Key 换 access_token（或用千帆统一网关直接鉴权）；
4. 国内支付/企业可开票。

## 5. 平台配置
```
WENXIN_API_KEY=...
WENXIN_BASE_URL=https://qianfan.baidubce.com/v2
```

## 6. 调用示例
```js
import OpenAI from 'openai';
const c = new OpenAI({ apiKey: process.env.WENXIN_API_KEY, baseURL: 'https://qianfan.baidubce.com/v2' });
const r = await c.chat.completions.create({ model: 'ernie-4.0-8k', messages: [{ role: 'user', content: '你好' }] });
```

中文理解、搜索增强、企业知识库、政务/金融合规场景。
