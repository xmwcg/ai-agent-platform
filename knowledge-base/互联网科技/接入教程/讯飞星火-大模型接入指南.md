# 讯飞星火（iFlytek Spark）大模型接入指南

## 1. 官方资源
- 开放平台：https://www.xfyun.cn
- Spark API 文档：https://www.xfyun.cn/doc/spark/Web.html
- 控制台：https://console.xfyun.cn

## 2. 接入地址
- BaseURL（OpenAI 兼容网关）：`https://spark-api-open.xf-yun.com/v1`（社区/官方兼容网关）
- 原生接口：`https://spark-api.xf-yun.com/v1/chat/completions`（需签名）。

## 3. 主要模型（参考，以官方为准）

| 模型 ID | 特点 |
|------|------|
| generalv3.5 / spark-max | 旗舰 |
| generalv3 / spark-pro | 通用 |
| spark-lite | 轻量低成本 |
| spark-vision | 视觉多模态 |

> 价格以讯飞开放平台计费页为准；新用户赠送 token 包。

## 4. API Key 申请
1. 注册 xfyun.cn 并实名；
2. 控制台 → 创建应用，获取 APPID / APIKey / APISecret；
3. 国内支付。

## 5. 平台配置
```
XFSPARK_API_KEY=...
XFSPARK_BASE_URL=https://spark-api-open.xf-yun.com/v1
```

## 6. 调用示例
```js
import OpenAI from 'openai';
const c = new OpenAI({ apiKey: process.env.XFSPARK_API_KEY, baseURL: 'https://spark-api-open.xf-yun.com/v1' });
const r = await c.chat.completions.create({ model: 'generalv3.5', messages: [{ role: 'user', content: '你好' }] });
```

## 7. 适用场景
语音+大模型融合、教育、办公、硬件端侧、中文场景。
