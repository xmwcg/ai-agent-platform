# 互联网/科技 · 大模型应用指引

## 1. 典型场景
- 代码生成/补全/Review（AI 编程）
- 技术文档问答（见 客服知识库）
- 内部知识库 RAG
- Agent 自动化（CI/CD、运维）
- 数据分析与可视化

## 2. 模型选型
| 任务 | 推荐模型 | 理由 |
|------|------|------|
| 代码 | claude / deepseek-coder / qwen-coder | 代码强 |
| 通用 | gpt-4o / qwen-plus | 均衡 |
| 成本 | deepseek-chat / glm-4-flash | 低价 |

## 3. 架构建议
- 统一网关：本平台 `provider-catalog` 聚合多供应商，按成本/质量路由。
- RAG + MCP 构成「可行动」的 AI 助手。
- 成本闸门：`billing.ts` 的 `PLAN_AI_BUDGET_FEN` 控制单日成本。
