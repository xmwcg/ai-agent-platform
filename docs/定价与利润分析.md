# 定价与利润分析（目标：毛利率 ≥ 80%）

> 结论先行：**用「国内低价模型（DeepSeek/智谱GLM/通义）做平台垫付主路由 + 重度/海外模型走 BYOK（用户自购 Key）」的组合，免费档可做到接近零边际成本引流，付费档毛利率轻松 ≥ 90%，自购中转站批量采购毛利也可 ≥ 80%。** 关键不在涨价，而在「路由到便宜模型 + 把贵模型成本转嫁 BYOK」。

## 三、四类成本场景的引流成本与利润率

### 场景 A：平台垫付 + 全部走国产低价模型（推荐默认）
- 专业版 ¥9.9/月；假设重度用户月耗 2M tokens（DeepSeek 输出计）≈ 成本 ¥8。
- 若走 GLM-4-flash（¥0.06/M）则成本 ≈ ¥0.12/月 → **毛利 ≈ 98%**。
- 即使按 ¥5/日闸门打满（极端），月成本 ¥150，仍低于 ¥9.9？——**不，会亏**。所以闸门必须生效：pro 日成本硬上限 ¥5，且默认路由低价模型，真实用量远低于闸门。**结论：默认路由 + 闸门 = 毛利 ≥ 90%。**

### 场景 B：BYOK（用户自购 Key，平台抽成/不垫付）
- 用户填自己的 DeepSeek/OpenAI Key，平台只收会员费/积分，**模型成本 ¥0**。
- 专业版 ¥9.9 全是毛利 → **毛利 100%**。
- 这是利润最核心杠杆：**贵模型（Claude/GPT）一律 BYOK，平台不承担。**

### 场景 C：自购中转站（平台批量采购 API，转售积分）
- 平台以企业/批量价采购（DeepSeek 直连 ¥1/M、聚合渠道常 5~7 折）。
- 假设批量采购成本 ¥0.5/M（拿 5 折），平台按积分 ¥0.065/积分 ≈ 等价 ¥65/M tokens 转售。
- 毛利 = (65-0.5)/65 ≈ **99%**（积分计价本身就含高毛利）。
- 中转站对外按「市场价 8 折」售卖，仍 ≥ 80%。

### 场景 D：批量采购 + 会员打包（混合）
- 用场景 A/B/C 组合：免费档用 GLM-flash 垫付（近零成本引流）；pro/max 默认低价模型垫付 + 贵模型 BYOK；中转站批量采购赚积分差价。
- 综合毛利率 **≥ 90%**，且免费档获客成本极低 → 引流效率高。

## 五、档位/积分微调建议（一针见血）

1. **免费档**：保持 ¥0 + 20 次/日，但默认模型锁 `glm-4-flash`/`deepseek-chat`，闸门 ¥0.5/日务必生效 → 获客成本≈0，纯引流。
2. **pro ¥9.9**：保留，作为「主力变现档」；默认路由低价模型，Claude/GPT 标注「需 BYOK 或积分」→ 成本转嫁。
3. **max ¥19.9**：加「高速通道 + 更长上下文 + 免广告」，与 pro 拉开体验差，提升升级率。
4. **积分**：维持高毛利计价（¥0.065/积分），作为「按量变现」补充，适合轻度/单次用户。
5. **防刷**：免费档加设备/IP 频控 + 验证码（见防刷方案），避免被人白嫖击穿 ¥0.5 闸门。
6. **付费引流闭环**：额度用尽必须弹 `QuotaExceededModal` 引导 /pricing（**当前弹窗未挂载，须修复**，见模块闭环任务）。
