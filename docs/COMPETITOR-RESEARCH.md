## 一、各平台商业模式汇总

### 1. 硅基流动 SiliconFlow
| 维度 | 做法 |
|------|------|
| 免费层 | 开源模型（Qwen2.5-7B等）永久免费调用 |
| 付费层 | 按量计费，¥0.5-4/百万Token |
| 引流方式 | 新用户赠送额度 → 用完提示充值 |
| 会员体系 | 无独立会员，纯按量+企业套餐 |
| 亮点 | 多模型聚合，API标准化，国产模型优先 |

### 2. 扣子 Coze（字节跳动）
| 维度 | 做法 |
|------|------|
| 免费层 | 基础Bot免费创建，每日限额 |
| 付费层 | 专业版 ¥99/月，企业版按需 |
| 引流方式 | 模板市场 + Bot商店 + 社区 |
| 会员体系 | 免费/专业/企业三级 |
| 亮点 | Bot商店生态，插件市场，知识库RAG |

### 3. DeepSeek
| 维度 | 做法 |
|------|------|
| 免费层 | Web端免费对话 |
| 付费层 | API按量：¥1-16/百万Token |
| 引流方式 | 开源模型 + 极低成本 |
| 会员体系 | 无独立会员，纯API计费 |
| 亮点 | 开源模型领导者，成本约GPT 1/50 |

### 4. 豆包 Doubao（字节跳动）
| 维度 | 做法 |
|------|------|
| 免费层 | 基础对话免费 |
| 付费层 | 豆包Pro会员 ¥30/月 |
| 引流方式 | APP+Web+小程序全覆盖 |
| 会员体系 | 免费/Pro两级 |
| 亮点 | 多端覆盖，语音交互，小程序生态 |
