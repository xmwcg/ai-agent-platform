## 二、本轮发现并修复的上线阻断项

### P0-1 支付方式前后端契约不一致

- 问题：前端读取 `{ key, label, enabled }`，后端却返回 `{ id, name, icon }`。
- 影响：即使真实微信支付已配置，价格页也可能无法展示支付入口。
- 修复：统一为 `{ key: 'wechat', label: '微信支付', enabled: boolean }`；生产环境只暴露微信支付。

### P0-2 已支付但权益不生效

- 问题：订单履约服务混用旧 `order.model.ts` 与当前 `Order.ts`，路由还把订单号字符串传给只接受旧订单文档的函数。
- 影响：订阅、积分包、ProjectGrade 权益、金网通 License 可能出现“支付成功但未开通”。
- 修复：重写统一履约入口 `fulfillPaidOrder/fulfillOrder`，支持订单号/订单文档，增加原子履约锁、失败状态、幂等重试和正确订单字段。

### P0-3 Webhook 成功事件被当作非成功事件

- 问题：Stripe/微信网关返回值缺少 `success`，Webhook 路由直接跳过履约。
- 修复：补齐 Stripe HMAC 验签、微信 RSA-SHA256 验签、AES-256-GCM 解密、成功事件识别、重放保护和重复事件幂等。

### P0-4 Outbox 缺少必填幂等键

- 问题：`OutboxEvent.idempotencyKey` 为必填，但支付确认写入时未提供。
- 影响：Mock 支付、积分充值等链路返回 500。
- 修复：统一使用 `payment-confirmed:<orderNo>`，改为原子 upsert。

### P0-5 `/ai-chat` 目录斜杠重定向

- 线上旧配置现象：`/ai-chat` 返回 `301 Location: http://aibak.site/ai-chat/`，随后被 Cloudflare 拦截为 403。
- 修复：全部实际 Nginx 配置移除 `$uri/`；Caddy 生产契约统一使用 `try_files {path} /index.html`；构建产物确认不存在 `dist/ai-chat` 冲突目录。
- 涉及：`client/nginx*.conf`、`deploy/nginx-runtime.conf`、`deploy/Caddyfile.aibak-site`。

### P1-1 页面出现字面量 `` `r`n ``

- 位置：顶部通知铃铛与用户区之间。
- 修复：恢复为真实换行，不再渲染异常文本。

### P1-2 Guard 产品失效外链与不可验证宣传

- 问题：两个 CTA 指向不存在/不可访问的 GitHub 仓库，并展示未发布的 npm 命令。
- 修复：改为站内 `/contact?product=guard` 部署包申请；同步修订“开源免费/GitHub 可审计”等未验证文案。

### P1-3 前端高危依赖收敛

- 移除仅用于空 Provider 的 `react-query`。
- 移除存在无修复高危漏洞的 `xlsx`，资产报表改为 UTF-8 CSV（Excel/WPS 可直接打开）。
- 升级 `react-router-dom` 到当前最新兼容版本。
- 服务端移除未直接加载、仅由 `npx` 调用的 MCP Server 依赖。
- 服务端停用存在高危传递依赖的 CloudBase Node SDK 直连；AI 对话继续走已验证的 CloudBase 云函数代理和统一网关兜底。

### P1-4 SEO 与产品收录

- 为 `/guard`、`/shop` 增加独立标题和描述。
- Sitemap 新增 `/shop`、`/guard`、`/transync`、`/flow`、`/about`、`/contact`。
- Robots 同步允许公开产品页，Sitemap 34 条均映射到真实路由。

## 四、上线前必须执行的部署动作

1. 将本报告对应提交合入 `main`。
2. 将 `main` 合入受保护的 `deploy/production`。
3. 由生产 watcher 拉取不可变镜像并发布静态资源。
4. 生产验证：
   - `https://aibak.site/ai-chat` 必须直接 200，不得再返回 `http://.../ai-chat/`。
   - `/api/health` 的 MongoDB、Redis、revision、镜像摘要必须全部健康。
   - `/api/billing/payment-methods` 必须只返回一条启用的微信支付。
   - 创建测试订单后，Webhook/主动查单必须使 `paymentStatus=paid` 且 `fulfillmentStatus=fulfilled`。
